# infra – Wiederverwendbare Arbeits-Infrastruktur

Enthält: Server-Setup-Standards, KI-Prompts, Projektvorlagen.

## Struktur
- ansible/       Bootstrap-Playbooks (Hardening, Basis-Setup)
- compose/       Docker-Compose-Stapel pro Service
- inventory/     Server-Inventar (hosts.yml)
- backup/        Backup-Skripte & -Konfiguration
- prompts/       Wiederverwendbare KI-Prompts
- templates/     Vorlagen (PROJECT.md, .aider.conf.yml, .gitignore)
